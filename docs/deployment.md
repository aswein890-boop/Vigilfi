# Deployment (Vercel)

1. Push this repository to GitHub.
2. Create a new project in Vercel and import the GitHub repository.
3. Build command: `npm run build` — Output directory: (default for Next.js)
4. Vercel will automatically set production configuration. No environment variables are required.

Notes

- The app is client-side; ensure you enable HTTPs and configure canonical domain in Vercel settings.
