# SEO & Content Strategy for VigilFi

This document describes the SEO work included in the VigilFi prototype and next steps to rank for target keywords related to emergency funds, financial resilience, and survival runway.

What was implemented

- Long-form landing content (detailed, educational, 1500+ words) placed in the primary landing page to target high-intent queries.
- Structured data: JSON-LD FAQ schema to increase SERP visibility for common queries.
- On-page SEO: dynamic metadata, canonical tag, OpenGraph/Twitter meta, and preconnect for fonts.
- Sitemap and robots.txt added for crawlability.
- Internal linking: clear anchors for How / Score / Docs and visible content hierarchy to improve crawl path.
- Performance optimizations: lazy-loading charts & PDF libraries, preconnect to font origins, and minimized bundle for initial load.

SEO next steps (recommended)

1. Publish long-form blog posts and case studies targeting keywords such as:
   - "emergency fund calculator"
   - "how long can I survive without income"
   - "financial resilience score"
2. Add server-side rendered landing pages for city-specific content and long-tail keywords.
3. Add canonicalized, shareable OG images per landing page.
4. Create a small site map of topical content (guides, calculators, FAQs) and publish regularly.
